# Dynamic List View for Odoo

## Overview

A powerful module that allows users to drag and drop columns in list views to reorder them. Column order is saved per model in browser localStorage, making your preferred layout persistent across sessions.

## 🚀 Features

- ✅ **Drag & Drop Columns** - Simply drag any column header to reorder
- ✅ **Persistent Order** - Column order is saved per model in localStorage
- ✅ **Works Everywhere** - Compatible with all list views in Odoo
- ✅ **No Database Dependencies** - Pure frontend module
- ✅ **Dark Mode Support** - Adapts to your Odoo theme
- ✅ **Lightweight** - Minimal performance impact

## 📦 Installation

1. Download the module from Odoo Apps Store
2. Place the module in your Odoo addons directory
3. Update the apps list: `Settings > Apps > Update Apps List`
4. Search for "Dynamic List View" and click Install

## 📱 How to Use

1. Go to any list view in Odoo (Contacts, Products, Sales Orders, etc.)
2. Hover over a column header - you'll see a grab cursor
3. Click and drag the column header
4. Drop it at the desired position
5. Your column order is automatically saved!

## 💡 Perfect For

- Customizing list views without developer mode
- Quickly rearranging columns to match your workflow
- Making important columns more accessible

## 🔧 Technical Details

- **No database dependencies** - Pure frontend module
- **Pure JavaScript** - Built with OWL framework
- **Lightweight** - Minimal performance impact
- **localStorage** - Order saved per model in browser storage
- **Compatible** - Works with Odoo 18 (Community or Enterprise)

- Odoo 18.0 (Community or Enterprise)
